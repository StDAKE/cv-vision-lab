使用说明

四区联动

四个区域共享同一份状态。改动任何参数，画面、矩阵、代码同时更新。

A 区

1/2/3/4 切换 并排 / 滑块 / 差分 / 叠加。滚轮缩放，拖拽平移，点击取像素探针。

B 区

C 区

算子与参数。每个参数旁标注教案出处，超出合理范围会给教学提示。

D 区

真实可运行的 Python 代码。播放时逐行高亮，变量面板显示当前中间值。
