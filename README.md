# CV 可视化教学台 · 使用说明

配套《深度学习与计算机视觉》前 5 次课教案的可视化教学辅助软件。

## 一、两种运行方式

### 1. 桌面版（推荐课堂使用）
双击 `desktop/dist/CV可视化教学台.exe`（约 77 MB，免安装、免联网、单文件）。
- 界面即开即用，分辨率按 1080P 设计，也支持全屏（`F` 键或右上角"全屏"按钮）。
- 数据完全本地，不上传任何内容。

### 2. 网页版
方式 A：在 `app/` 目录下启动任意静态服务后访问 `index.html`，例如：
```
cd app
python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000
```
方式 B：直接用 VS Code 的 Live Server 等插件打开 `app/index.html`。
> 注意：网页版必须通过 http 服务打开，直接双击 file:// 会因浏览器安全策略无法创建算子线程。

## 二、四区布局

| 区域 | 内容 | 常用操作 |
|---|---|---|
| 左上 A 区 | 原图 / 处理后对比（并排、滑块、差分、叠加四种模式），直方图叠加，PSNR / SSIM / 噪声σ / 边缘能量指标 | 滚轮缩放、拖拽平移、点击取像素探针；`1/2/3/4` 切模式 |
| 左下 B 区 | 图像的数字本质：10×10 像素矩阵（热力色 + 数值），灰/R/G/B/H/S/V 七个通道，卷积核、逐项乘加算式、HWC/CHW 两种读法 | 点通道 chip 切换；HWC/CHW 按钮切换布局 |
| 右上 C 区 | 知识点导航 + 算子库（按组折叠）+ 参数滑块 + 处理栈（流水线顺序即结果） | 拖滑块实时联动四区；处理栈可上移/下移/删除/清空 |
| 右下 D 区 | 与算子一一对应的真实 OpenCV Python 代码，当前执行行高亮，变量面板显示中间值 | `空格` 播放/暂停（滑窗逐格计算、中值排序动画）；`←/→` 单步；"复制代码"可粘贴到本地 Python |

## 三、快捷键

`空格` 播放/暂停 · `←/→` 单步 · `R` 复位当前知识点 · `F` 全屏 · `1/2/3/4` A 区视图模式

## 四、内容地图

- **第 1 讲 · 概述**：整门课的坐标、四种视觉输出、三项代价（简化示意，不写代码）
- **第 2 讲 · 数字本质**：采样与量化、混叠、RGB/HSV/灰度、HWC/CHW
- **第 3 讲 · 滤波与边缘**：均值 / 高斯 / 中值 / 双边、Sobel、Canny、Laplacian、形态学、LBP
- **第 4 讲 · 噪声与增强**：噪声注入、直方图均衡、CLAHE、亮度对比度、USM 锐化、"先锐化后降噪"反例
- **第 5 讲 · 归一化与流水线**：Z-score / Min-Max、letterbox / crop / stretch、预处理顺序
- 右上角"演示预设"循环三组对照：椒盐+中值（正确）、椒盐+高斯（越治越糟）、先锐化再降噪（顺序反了）

## 五、素材与自定义

- 内置素材**没有实体图片文件**，而是在 `src/assets/images.js` 里用 Canvas 2D + 固定随机种子**程序化合成**（零依赖、零体积、缺陷位置可控、每次生成完全一致）。
- 顶栏左侧**"素材"下拉**可切换 8 项：零件·良品 / 细划痕 / 麻点 / 光照不均 / 灰阶渐变 / 色卡 / 同一件·光照正常 / 同一件·光照偏暗（后两张只差曝光，用于第 4 讲"分布偏移"）。当前素材名同时显示在左下状态栏。
- 点"导入图像"可选择本地图片（自动缩放到 880px 工作分辨率）；导入后下拉会切到"自定义图片…"。
- 点"截图"导出当前处理结果 PNG。

## 六、为深度学习预留的接口

代码层面已定义统一抽象（`src/operators/registry.js`）：
- `OperatorSpec`：参数 schema + `run()` + Python 代码模板，新增算子只需注册一项；
- 图像统一为 `{w, h, c, d}` 张量结构，后续可直接扩展 HWC→CHW→NCHW 的 Tensor 与 `InferenceBackend`（加载 ONNX/浏览器推理）；
- `LectureModule`：每讲一个模块（主题 + 预设），新增"第 6 讲 · 卷积神经网络"等只需在 `src/modules/lectures.js` 追加。

## 七、目录结构

```
app/                  网页版（纯静态，无任何第三方运行时依赖）
  index.html
  css/app.css
  src/core/           算子线程、纯 JS 图像内核(imgops)、像素工具、指标、执行轨迹
  src/operators/      算子注册表 + 20 个算子实现
  src/ui/             A/B/C/D 四区视图 + 处理栈
  src/modules/        讲次与知识点编排
  src/assets/         程序合成素材
desktop/              Electron 桌面壳
  main.js             内建本地静态服务 + 窗口
  app/                同 app/（打包时嵌入）
  dist/CV可视化教学台.exe   打包产物（portable，双击即用）
```
